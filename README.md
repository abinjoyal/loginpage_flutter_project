# Fitness App - Login & Sign Up UI

A modern, responsive, and sleek dark-themed login and sign-up user interface built with Flutter and Dart. Designed with a custom color palette, soft keyboard overflow handling, input validation, and smooth page transitions.

## Features

- **Modern Dark Theme:** Custom linear gradients (`#1C2E05` to `#000000`) paired with vibrant neon lime accent (`#D0FD3E`).
- **Keyboard-Responsive Layout:** Prevents bottom `RenderFlex` overflow errors when soft keyboard appears.
- **Form Validation:** Input validation for email format and password length requirements.
- **Password Visibility:** Toggleable password obscure option.
- **Interactive Controls:** Tap feedback for "Forgot Password?", social login buttons, and navigation links.
- **Smooth Page Transitions:** Fade transitions between screens without white canvas flash.

## Tech Stack

- **Framework:** Flutter (v3.10+)
- **Language:** Dart (SDK ^3.10.4)
- **UI Architecture:** Material Design 3

### Prerequisites

- Flutter SDK (v3.10.4 or higher)
- Dart SDK
- Git

### Installation & Run

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/abinjoyal/flutter_project.git
   ```

2. **Navigate to Project Directory:**
   ```bash
   cd "Login Page"
   ```

3. **Install Package Dependencies:**
   ```bash
   flutter pub get
   ```

4. **Run Application:**
   ```bash
   flutter run
   ```
